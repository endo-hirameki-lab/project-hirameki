# HIRAMEKI AI Studio

> AI-powered Content Automation Platform

## Vision

HIRAMEKI AI Studio is an AI-powered platform designed to automate the creation, publishing, and improvement of educational short-form content.

The first project is the YouTube channel **"ひらめきAIスタジオ"**, where AI assists with:

* Finding video ideas
* Writing scripts
* Creating videos
* Publishing content
* Analyzing performance

The long-term goal is to build a reusable AI content automation system.

The YouTube channel serves as the first validation project for the HIRAMEKI AI Studio platform.

---

## Project Goals

The system aims to automate:

* Topic research
* Script generation
* Fact checking
* Voice generation
* Video creation
* Thumbnail creation
* Social media publishing
* Performance analysis
