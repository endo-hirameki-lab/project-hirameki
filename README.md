# Project HIRAMEKI

> AI-powered Content Automation Platform

## Vision

Project HIRAMEKI is an AI-powered platform designed to automate the creation, publishing, and improvement of educational short-form content.

The first project is the YouTube channel **"ひらめきラボ"**, where AI assists with:

- Finding video ideas
- Writing scripts
- Creating videos
- Publishing content
- Analyzing performance

The long-term goal is to build a reusable AI content automation system.

---

## Project Goals

The system aims to automate:

- Topic research
- Script generation
- Voice generation
- Video creation
- Thumbnail creation
- Social media publishing
- Performance analysis
